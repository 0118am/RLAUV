## 必须保留的结论

- `u` 与 `p` 没有独立振荡，相关输入列为 `NaN`，不是零。
- vertical/heave 给出负附加质量，互易补齐后的已测子块也有负特征值；未取绝对值、未裁剪。
- `D_1_eff` 吸收了拖航速度相关同相项和未分离的附加质量 Coriolis 项；在补齐 `u/p` 附加质量并显式分离 `C_A` 前，不应直接与仿真器的完整 `C_A` 重复叠加。
- Downloads 中缺少 42 条 vertical 试次；本次运行从 Git 历史对象 `425ab436d1ae7853881045d6a8c4f5f37350d461` 只读恢复这些原始记录，未恢复或改写用户删除的工作树文件。
