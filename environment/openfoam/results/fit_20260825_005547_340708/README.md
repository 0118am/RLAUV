## 数学模型和辨识推导

按 body FLU、移动 COM 定义

```text
nu_r  = [u,v,w,p,q,r]^T                    相对水速度
tau_h = [X,Y,Z,K,M,N]^T                    流体作用于艇体的广义力
tau_h = -M_A nu_dot_r - C_A(nu_r;M_A)nu_r
        -D_L nu_r - D_Q(|nu_r| .* nu_r)
```

### 稳态平移阻尼

对激励自由度 `j` 和正速度 `s>0`，正负工况的半差去掉静态偏置：

```text
y_i(s) = [tau_i(+s) - tau_i(-s)] / 2
       = -(D_L)_{ij} s - (D_Q)_{ij} s^2
```

用 `s1=0.08`、`s2=0.40 m/s` 构造

```text
[y_i(s1)]   [-s1  -s1^2] [(D_L)ij]
[y_i(s2)] = [-s2  -s2^2] [(D_Q)ij]
```

对六个载荷响应分别做列尺度归一化最小二乘，因此每个单轴激励得到矩阵完整一列。两档速度
恰好拟合两个系数，所以平移 NRMSE 约 `5e-16` 到 `7e-16` 只是数值上精确插值，不能当成独立
验证误差。

### 振荡附加质量与转动阻尼

令单轴速度 `nu_j(t)=V sin(omega t)`，则加速度 `V omega cos(omega t)` 与速度正交。
完整周期中对每个响应通道求解

```text
tau_i(t) = -M_A,ij nu_dot_j(t)
           -D_L,ij nu_j(t)
           -D_Q,ij |nu_j(t)|nu_j(t)
```

即设计矩阵三列为 `[-nu_dot_j, -nu_j, -|nu_j|nu_j]`。平移发布附加质量来自每自由度一个低幅
工况；转动发布值把 0.2 和 0.8 rad/s 两幅值联合回归，低幅 0.08 rad/s 工况只作为幅值依赖
交叉检查。转动总载荷 NRMSE 为 p/q/r = 2.20% / 2.85% / 2.33%；扣除附加质量后的阻尼
NRMSE 为 11.48% / 14.78% / 11.80%。

### 对称性和互易性

左右反射的广义奇偶向量为 `p=[1,-1,1,-1,1,-1]`。任意系数矩阵 `A` 必须满足
`A=PAP`，其中 `P=diag(p)`；因此只有 `p_i p_j=1` 的条目允许非零，即 `[u,w,q]` 和
`[v,p,r]` 两个块。允许块内的 CFD 横轴响应被保留，禁止块间项置零。附加质量再施加互易性：

```text
M_A = (M_raw + M_raw^T) / 2
```

原始附加质量非对称 Frobenius 范数为 0.05883。发布矩阵特征值为
`[0.12979, 0.16692, 0.40946, 13.11370, 19.42199, 34.86964]`，均为正。

把 `M_A` 分块并令附加动量 `h=M_A nu_r=[h_v;h_omega]`，运行时使用满足
`nu_r^T C_A nu_r=0` 的 Coriolis 形式

```text
C_A = [[0,       -S(h_v)],
       [-S(h_v), -S(h_omega)]]
```

`S(x)y=x×y`。PhysX 环境通过求解包含 `M_RB+M_A` 的加速度方程施加附加质量，而不是用
有限差分加速度再产生外力；Coriolis 项仍显式保留。

完整 `6×6` 数字见 `config_updates.json`；矩阵行是 `[X,Y,Z,K,M,N]`，列是

说明全响应耦合不可忽略，也说明仍需多轴试验验证。

## 已知限制

- `D_L` 对称部分的特征值含 `-0.1924` 和 `-0.1276`。虽然全部线性、二次主对角线为正，
  该全矩阵拟合不能保证任意多轴速度下全局被动；这是真实诊断，不应隐藏或自动投影掉。
- 没有网格收敛、独立重复工况或实验水池验证；无棱柱层降低黏性阻力可信度。
- 不包含自由液面、池壁/池底、工作桨尾流、多轴混合二次阻力和粗糙度效应。
- 原始 cases 和 force.dat 不在 Git，因此可从脚本重算，但不能仅靠本提交复核每个时刻的 CFD
  原始载荷。

这些限制是结果被标成 `preliminary` 的原因，不是发布器的拒绝条件。
